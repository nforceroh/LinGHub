# UI v2 reference screenshots

Screenshots of the UI being aimed at. They are **reference, not specification**:
the goal is something similar, not a copy. The decisions they inform live in
[../spec.md](../spec.md).

Naming: `NN-screen-name.png`, numbered in the order they were shared, named for
the screen they show rather than for the app they came from.

| File | Screen |
| --- | --- |
| `01-home-greeting.png` | Home / greeting: one device card centred on an empty canvas |

## Adding one

Drop the image in this folder and add a row to the table above. If it shows a
screen the spec does not yet describe, add a subsection to
[../spec.md](../spec.md) §3 recording what it shows and which facts about it
have been verified against the hardware.
